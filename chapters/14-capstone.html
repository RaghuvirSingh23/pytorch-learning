Chapter 14 Capstone Project

Rebuild microgpt in PyTorch, starting from an empty file, laid out the way real training and inference code is: data, batching, model, training loop, checkpoints, KV-cache generation, and a benchmark. Then make it fast and measure it. There are seven milestones and a set of stretch goals; each milestone has a check you run, and every output on this page comes from actually running the reference solution.

What you will build

One file, gpt.py, with three commands:

  • python gpt.py train: download names.txt, train the 4,192-parameter microgpt on batches of 32 names with AdamW, evaluate on the held-out names, save a checkpoint. --resume continues from it.
  • python gpt.py sample: load the checkpoint and generate names with temperature and top-k, using a KV cache.
  • python gpt.py bench: training tokens/s, cached vs uncached generation tokens/s, and a torch.profiler table.

Same model, same data split and same evaluation as microgpt.py, so the numbers compare directly. On an Apple Silicon (M4 Pro) laptop CPU, one thread, this is what the reference solution measured. Your numbers will differ.

NAMES_URL = "https://raw.githubusercontent.com/karpathy/makemore/988aa59/names.txt"
IGNORE_INDEX = -100  # cross_entropy skips targets with this value


# --- 1. data and tokenizer ---------------------------------------------------
def load_names(path="names.txt", seed=42):
    """Download once, shuffle with a fixed seed, split 90/10 (the same split as microgpt.py)."""
    if not os.path.exists(path):
        urllib.request.urlretrieve(NAMES_URL, path)
    with open(path) as f:
        docs = [line.strip() for line in f if line.strip()]
    random.Random(seed).shuffle(docs)
    split = int(0.9 * len(docs))
    return docs[:split], docs[split:]


class Tokenizer:
    """One id per character; BOS (the last id) marks both the start and the end of a name."""

    def __init__(self, docs):
        chars = sorted(set("".join(docs)))
        self.stoi = {c: i for i, c in enumerate(chars)}
        self.itos = {i: c for c, i in self.stoi.items()}
        self.bos = len(chars)
        self.vocab_size = len(chars) + 1

    def encode(self, doc):
        return [self.bos] + [self.stoi[c] for c in doc] + [self.bos]

    def decode(self, ids):
        return "".join(self.itos[i] for i in ids if i != self.bos)

This is microgpt's encode and decode wrapped in a class, so the vocabulary travels with the object instead of living in module globals.

EX 14.2 medium Milestone 2 · Dataset, collate and a resumable batch stream

NamesDataset(docs, tok, block_size) returns one name as a 1-D LongTensor of token ids, truncated to block_size + 1 tokens (at most block_size predictions, like microgpt's make_training_pair). Its collate(batch) turns a list of those into (inputs, targets), both (B, T) where T is the longest name in the batch plus one: inputs are the ids without the last token, right-padded with BOS; targets are the ids shifted by one, right-padded with IGNORE_INDEX = -100.

Then batches(ds, batch_size, seed, start_step=0): an endless iterator over shuffled batches that drops the last partial batch of each epoch. Seed the shuffle per epoch so the stream is a pure function of (seed, step); milestone 5 needs that to resume exactly.

Acceptance check

The check prints a padded batch, then shows that the loss is unchanged when the logits at pad positions are replaced by garbage, and that it equals the mean over real tokens only.

Hints

  • Pad the inputs with a real token id. An embedding lookup of -100 is an index error; the value doesn't matter because its target is ignored and, being at the end, no real position can attend to it.
  • torch.full((B, T), value, dtype=torch.long), then copy each name into its row.
  • DataLoader(ds, batch_size, shuffle=True, drop_last=True, generator=g, collate_fn=ds.collate) with g = torch.Generator().manual_seed(seed + epoch); itertools.islice skips the batches already done in the current epoch.
  • Leave num_workers at 0. The whole dataset is a 228 KB list in memory; worker processes would cost more than they save (q27).

# --- 2. batching -------------------------------------------------------------
class NamesDataset(Dataset):
    def __init__(self, docs, tok, block_size):
        self.docs, self.tok, self.block_size = docs, tok, block_size

    def __len__(self):
        return len(self.docs)

    def __getitem__(self, i):
        ids = self.tok.encode(self.docs[i])[: self.block_size + 1]  # at most block_size predictions
        return torch.tensor(ids, dtype=torch.long)

    def collate(self, batch):
        """Right-pad to the longest name: pad inputs are BOS, pad targets are IGNORE_INDEX."""
        T = max(len(ids) for ids in batch) - 1
        inputs = torch.full((len(batch), T), self.tok.bos, dtype=torch.long)
        targets = torch.full((len(batch), T), IGNORE_INDEX, dtype=torch.long)
        for row, ids in enumerate(batch):
            inputs[row, : len(ids) - 1] = ids[:-1]
            targets[row, : len(ids) - 1] = ids[1:]
        return inputs, targets


def batches(ds, batch_size, seed, start_step=0):
    """Endless (inputs, targets) stream whose order depends only on (seed, epoch), so a run
    resumed at start_step sees exactly the batches the uninterrupted run would have seen."""
    per_epoch = len(ds) // batch_size
    epoch, skip = divmod(start_step, per_epoch)
    while True:
        g = torch.Generator().manual_seed(seed + epoch)
        loader = DataLoader(ds, batch_size, shuffle=True, drop_last=True,
                            generator=g, collate_fn=ds.collate)
        yield from itertools.islice(loader, skip, None)
        epoch, skip = epoch + 1, 0

The longest name in names.txt has 15 letters, so with BOS at both ends it is 17 tokens and 16 predictions: nothing is actually truncated here, but the dataset should not depend on that. Note how the last row (jori, 6 tokens) has 5 real targets followed by three -100s.

EX 14.3 medium Milestone 3 · The GPT module

Write GPTConfig with microgpt's numbers and a GPT(nn.Module) that takes idx of shape (B, T) and returns (logits, loss), logits (B, T, 27), loss None unless targets are given. Why 4,192 exactly, and why ln 27

The count matches microgpt because the module has the same nine matrices: two embedding tables (27×16 and 16×16), four 16×16 attention matrices, the MLP's 64×16 and 16×64, and the 27×16 head: 432 + 256 + 1,024 + 2,048 + 432 = 4,192. nn.Linear stores its weight as [out, in], the same layout as microgpt's weight lists, so even the shapes line up. It only matches because of two options: with PyTorch's defaults (bias=True on each nn.Linear, and a learnable weight in each nn.RMSNorm) the same architecture has 4,395 parameters: 171 biases (4 × 16 + 64 + 16 + 27) and 32 norm weights.

The initial loss is about ln 27 = 3.2958 because weights of size 0.08 give logits close to 0, so the softmax is nearly uniform over 27 tokens and every target gets probability about 1/27. A first loss far from ln(vocab) means a bug in the init or the loss.

Hints

  • Heads: w(x).view(B, T, H, D).transpose(1, 2). Back: y.transpose(1, 2).reshape(B, T, C) (q34).
  • register_buffer("mask", torch.tril(torch.ones(block, block, dtype=torch.bool)), persistent=False), then masked_fill(~mask[:T, :T], float("-inf")) before the softmax.

@dataclass
class GPTConfig:
    vocab_size: int = 27
    block_size: int = 16
    n_layer: int = 1
    n_embd: int = 16
    n_head: int = 4
    mlp_hidden: int = 64
    sdpa: bool = False  # use F.scaled_dot_product_attention instead of explicit math


# --- 3. model ----------------------------------------------------------------
class KVCache:
    """Preallocated keys and values for one layer, (B, H, block_size, D), filled left to right."""

    def __init__(self, batch_size, cfg, device=None):
        shape = (batch_size, cfg.n_head, cfg.block_size, cfg.n_embd // cfg.n_head)
        self.k = torch.zeros(shape, device=device)
        self.v = torch.zeros(shape, device=device)
        self.pos = 0

    def append(self, k, v):
        T = k.shape[2]
        self.k[:, :, self.pos : self.pos + T] = k
        self.v[:, :, self.pos : self.pos + T] = v
        self.pos += T
        return self.k[:, :, : self.pos], self.v[:, :, : self.pos]


class CausalSelfAttention(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.n_head, self.head_size, self.sdpa = cfg.n_head, cfg.n_embd // cfg.n_head, cfg.sdpa
        self.wq = nn.Linear(cfg.n_embd, cfg.n_embd, bias=False)
        self.wk = nn.Linear(cfg.n_embd, cfg.n_embd, bias=False)
        self.wv = nn.Linear(cfg.n_embd, cfg.n_embd, bias=False)
        self.wo = nn.Linear(cfg.n_embd, cfg.n_embd, bias=False)
        mask = torch.tril(torch.ones(cfg.block_size, cfg.block_size, dtype=torch.bool))
        self.register_buffer("mask", mask, persistent=False)  # True = may attend

    def forward(self, x, cache=None):
        B, T, C = x.shape
        q, k, v = (w(x).view(B, T, self.n_head, self.head_size).transpose(1, 2)
                   for w in (self.wq, self.wk, self.wv))  # each (B, H, T, D)
        start = 0
        if cache is not None:
            start = cache.pos
            k, v = cache.append(k, v)  # every key/value so far: (B, H, start + T, D)
        mask = self.mask[start : start + T, : k.shape[2]]  # rows: new queries, cols: all keys
        if self.sdpa:
            y = F.scaled_dot_product_attention(q, k, v, attn_mask=mask)
        else:
            att = (q @ k.transpose(-2, -1)) / math.sqrt(self.head_size)  # (B, H, T, S)
            att = att.masked_fill(~mask, float("-inf"))
            y = F.softmax(att, dim=-1) @ v  # (B, H, T, D)
        return self.wo(y.transpose(1, 2).reshape(B, T, C))


class Block(nn.Module):
    """microgpt's block: x + attn(rms_norm(x)), then x + mlp(rms_norm(x)); no norm weights."""

    def __init__(self, cfg):
        super().__init__()
        self.norm1 = nn.RMSNorm(cfg.n_embd, eps=1e-5, elementwise_affine=False)
        self.attn = CausalSelfAttention(cfg)
        self.norm2 = nn.RMSNorm(cfg.n_embd, eps=1e-5, elementwise_affine=False)
        self.fc1 = nn.Linear(cfg.n_embd, cfg.mlp_hidden, bias=False)
        self.fc2 = nn.Linear(cfg.mlp_hidden, cfg.n_embd, bias=False)

    def forward(self, x, cache=None):
        x = x + self.attn(self.norm1(x), cache)
        return x + self.fc2(F.relu(self.fc1(self.norm2(x))))


class GPT(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.cfg = cfg
        self.tok_emb = nn.Embedding(cfg.vocab_size, cfg.n_embd)
        self.pos_emb = nn.Embedding(cfg.block_size, cfg.n_embd)
        self.blocks = nn.ModuleList(Block(cfg) for _ in range(cfg.n_layer))
        self.lm_head = nn.Linear(cfg.n_embd, cfg.vocab_size, bias=False)
        for p in self.parameters():
            nn.init.normal_(p, mean=0.0, std=0.08)  # microgpt's make_matrix init

    @property
    def device(self):
        return self.lm_head.weight.device

    def forward(self, idx, targets=None, caches=None):
        B, T = idx.shape
        start = 0 if caches is None else caches[0].pos
        x = self.tok_emb(idx) + self.pos_emb(torch.arange(start, start + T, device=idx.device))
        for i, block in enumerate(self.blocks):
            x = block(x, None if caches is None else caches[i])
        logits = self.lm_head(x)  # (B, T, V)
        loss = None
        if targets is not None:
            loss = F.cross_entropy(logits.view(-1, logits.size(-1)), targets.view(-1),
                                   ignore_index=IGNORE_INDEX)
        return logits, loss

    def new_caches(self, batch_size):
        return [KVCache(batch_size, self.cfg, self.device) for _ in self.blocks]

Compare CausalSelfAttention.forward with microgpt's FastMicroGPT.forward: it is the same computation with a batch dimension in front. The KVCache class and the cache branches are milestone 6; the sdpa flag is a stretch goal. Both are harmless with their defaults.

EX 14.4 medium Milestone 4 · Training and evaluation

Write TrainConfig, then:

  • make_optimizer(model, tc): AdamW with microgpt's lr, betas and eps, weight decay on the 2-D parameters only, and a LambdaLR whose factor falls linearly from 1 to 0 over tc.steps, which is microgpt's 0.01 * (1 - progress).
  • train_step(...): forward, zero grads, backward, clip to global norm 1.0, optimizer step, scheduler step. Return the loss and the pre-clip gradient norm as Python floats.
  • evaluate(model, ds): under inference_mode, the token-weighted loss over the whole split (sum of every token's loss divided by the number of real tokens) and its perplexity, exp(loss).
  • fit(...): the loop, logging the mean loss of each window, the gradient norm, the LR and tokens/s.

Token-weighted matters because names have different lengths. Averaging per-batch means would weight a token in a batch of short names more than one in a batch of long names, and the result would change with the evaluation batch size. microgpt's evaluate_model sums token losses and divides by total predictions; do the same and you get the same 22,866 test tokens.

    batch_size: int = 32

# --- 4. training and evaluation ----------------------------------------------
def make_optimizer(model, tc):
    """AdamW with microgpt's betas, decay on matrices only, LR linearly decayed to 0."""
    params = list(model.parameters())
    groups = [{"params": [p for p in params if p.dim() >= 2], "weight_decay": tc.weight_decay},
              {"params": [p for p in params if p.dim() < 2], "weight_decay": 0.0}]
    groups = [g for g in groups if g["params"]]
    opt = torch.optim.AdamW(groups, lr=tc.lr, betas=tc.betas, eps=tc.eps)
    sched = torch.optim.lr_scheduler.LambdaLR(opt, lambda step: max(0.0, 1.0 - step / tc.steps))
    return opt, sched


def train_step(model, opt, sched, inputs, targets, grad_clip):
    model.train()
    _, loss = model(inputs.to(model.device), targets.to(model.device))
    opt.zero_grad(set_to_none=True)
    loss.backward()
    grad_norm = torch.nn.utils.clip_grad_norm_(model.parameters(), grad_clip)
    opt.step()
    sched.step()
    return loss.item(), grad_norm.item()


@torch.inference_mode()
def evaluate(model, ds, batch_size=512):
    """Token-weighted loss over a whole split: (sum of every token's loss) / (number of tokens)."""
    model.eval()
    total, count = 0.0, 0
    for inputs, targets in DataLoader(ds, batch_size, collate_fn=ds.collate):
        logits, _ = model(inputs.to(model.device))
        targets = targets.to(model.device)
        total += F.cross_entropy(logits.view(-1, logits.size(-1)), targets.view(-1),
                                 ignore_index=IGNORE_INDEX, reduction="sum").item()
        count += (targets != IGNORE_INDEX).sum().item()
    return total / count, math.exp(total / count)


def fit(model, opt, sched, tc, train_ds, step=0):
    """Train from `step` to tc.steps, logging the mean loss of each window and tokens/s."""
    it = batches(train_ds, tc.batch_size, tc.seed, start_step=step)
    window, tokens, t0 = [], 0, time.perf_counter()
    while step < tc.steps:
        inputs, targets = next(it)
        lr = opt.param_groups[0]["lr"]
        loss, grad_norm = train_step(model, opt, sched, inputs, targets, tc.grad_clip)
        window.append(loss)
        tokens += (targets != IGNORE_INDEX).sum().item()
        step += 1
        if step % tc.log_every == 0 or step == tc.steps:
            print(f"step {step:5d}/{tc.steps} | loss {sum(window) / len(window):.4f} | "
                  f"grad norm {grad_norm:.3f} | lr {lr:.5f} | "
                  f"{tokens / (time.perf_counter() - t0):,.0f} tok/s")
            window = []
    return step

train_step calls .item() twice per step. On a CPU that costs nothing; on a GPU each one is a sync (q45), and for a model this small you would keep the running loss on the device and read it every few hundred steps.

EX 14.5 medium Milestone 5 · Checkpoint and exact resume

save_checkpoint(path, model, opt, sched, step, tc) writes the model, optimizer and scheduler state dicts, the step, and both configs, atomically. load_checkpoint(path, device="cpu") rebuilds the model from the saved config, rebuilds the optimizer and scheduler, loads all three states and returns (model, opt, sched, step, tc). Wire up python gpt.py train --resume.

"Resume" means the run continues exactly as if it had never stopped. That needs three things restored: the weights; the optimizer state (Adam's m, v and step count per parameter, the state your apply_adam kept in adam_first_moments and adam_second_moments); and the position in the LR schedule and in the data, which is why batches takes start_step.

Acceptance check

Train 50 steps, save, take 3 more steps. Then load the checkpoint in a fresh model and take the same 3 steps. The losses must be bit-for-bit equal. A third run that loads only the weights (fresh AdamW, fresh schedule) matches on the first step, because that loss is computed before any update, and diverges after.

# --- 5. checkpoints ----------------------------------------------------------
def save_checkpoint(path, model, opt, sched, step, tc):
    state = {"model": model.state_dict(), "optimizer": opt.state_dict(),
             "scheduler": sched.state_dict(), "step": step,
             "model_config": asdict(model.cfg), "train_config": asdict(tc)}
    torch.save(state, path + ".tmp")
    os.replace(path + ".tmp", path)  # atomic: a crash never leaves a half-written checkpoint


def load_checkpoint(path, device="cpu"):
    ckpt = torch.load(path, map_location=device)  # weights_only=True: tensors and plain data only
    model = GPT(GPTConfig(**ckpt["model_config"])).to(device)
    model.load_state_dict(ckpt["model"])
    tc = TrainConfig(**ckpt["train_config"])
    opt, sched = make_optimizer(model, tc)
    opt.load_state_dict(ckpt["optimizer"])
    sched.load_state_dict(ckpt["scheduler"])
    return model, opt, sched, ckpt["step"], tc

Bit-identical resume works here because everything after the checkpoint is deterministic on a CPU: no dropout, no sampling, and a data order computed from (seed, step). With dropout you would also save and restore torch.get_rng_state(); on a GPU, see the determinism caveats in q29.

EX 14.6 hard Milestone 6 · Generation with a KV cache

microgpt's scalar gpt_step kept a key_cache and value_cache list and appended one key and value per position. Do the same with tensors:

  • KVCache: preallocated (B, H, block_size, D) buffers for keys and values plus a write position pos. append(k, v) writes the new T positions and returns everything written so far.
  • In attention, when a cache is passed: append the new keys and values, then let the T new queries attend to all start + T keys. The mask rows are the new queries' positions, mask[start:start+T, :start+T].
  • In GPT.forward: position ids start at caches[0].pos, not 0. Add new_caches(batch_size), one cache per layer.
  • generate(model, tok, n, prefix, temperature, top_k, use_cache, seed): sample n names as one batch. The first forward is the prefill (BOS plus the prefix, all at once); after that, the cached path feeds only the newest token, the uncached path re-feeds the whole sequence. Divide by temperature, apply top-k, sample, stop when every row has produced BOS, cut each row at its first BOS.

# --- 6. generation with a KV cache -------------------------------------------
@torch.inference_mode()
def generate(model, tok, n=10, prefix="", temperature=1.0, top_k=None,
             use_cache=True, seed=None, stop_early=True):
    """Sample n names as one batch. The first forward is the prefill (the whole prompt); after it
    the cached path feeds only the newest token. Rows that already ended keep sampling until all
    rows have; decoding cuts each row at its first BOS."""
    model.eval()
    g = None if seed is None else torch.Generator().manual_seed(seed)
    prompt = [tok.bos] + [tok.stoi[c] for c in prefix]
    idx = torch.tensor([prompt] * n, device=model.device)
    caches = model.new_caches(n) if use_cache else None
    x = idx
    for _ in range(model.cfg.block_size - len(prompt) + 1):
        logits, _ = model(x if use_cache else idx, caches=caches)
        logits = logits[:, -1, :] / temperature
        if top_k is not None:
            kth = torch.topk(logits, top_k).values[:, -1:]
            logits = logits.masked_fill(logits < kth, float("-inf"))
        probs = F.softmax(logits, dim=-1).cpu()  # sample on CPU: one seeded generator, any device
        x = torch.multinomial(probs, 1, generator=g).to(idx.device)
        idx = torch.cat([idx, x], dim=1)
        if stop_early and (idx[:, len(prompt):] == tok.bos).any(dim=1).all():
            break
    names = []
    for row in idx.tolist():
        new = row[len(prompt):]
        end = new.index(tok.bos) if tok.bos in new else len(new)
        names.append(tok.decode(row[: len(prompt)] + new[:end]))
    return names

Rows that finish early keep sampling until every row is done; the extra tokens are cut off by the decode loop. Real serving engines remove finished sequences from the batch and insert new requests in their place (continuous batching); here the batch is tiny and fixed, so wasting a few steps is simpler.

Reading the numbers

  • Training: about 177,000 tokens/s against microgpt's 22,800, roughly 7.8x, from batching alone: one Python-level step now processes 32 names.
  • Generation at batch 1: cached and uncached are almost the same. Each step is a dozen tiny ops on a 16-wide model, so per-op overhead dominates, and re-running up to 16 positions instead of 1 adds almost nothing.
  • Generation at batch 256: the cache is 4.7x faster. Uncached, each batch re-processes 256 × (1 + 2 + … + 16) = 34,816 positions; cached, 256 × 16 = 4,096. With 8.5x less work and enough rows to make work matter, the cache wins. This is the whole argument for KV caches, at toy scale.
  • The profile: 20 steps took 35 ms of CPU time, about 1.75 ms per step. aten::bmm is the attention matmuls: 120 calls, 6 per step (2 in forward, 4 in backward). aten::select has 33,616 calls of 0.25 µs each: on this CPU build a batched matmul over the 32 × 4 = 128 (batch, head) matrices is executed matrix by matrix, and each one shows up as select calls and the as_strided calls beneath them. Profiled on its own, the score matmul at T = 16, (128, 16, 4) @ (128, 4, 16), records 384 selects (3 per matrix), while the smaller (128, 9, 4) @ (128, 4, 9) records none. enumerate(DataLoader) is your Python collate at 11%.

The lesson: this model is overhead-bound, not compute-bound. The time goes on per-op dispatch, view bookkeeping and Python, not arithmetic. That is also why one thread beats eight here, and why a GPU would not help (stretch goals below): the fix for overhead is fewer, bigger ops (fused attention, compilation, larger batches), not more FLOPs.

Multi-query attention changes wk and wv to project to one head (C -> D) and lets broadcasting share that head across the 4 query heads. The cache now holds 1 head instead of 4:

class MQAttention(CausalSelfAttention):
    """Multi-query attention: every query head shares ONE key head and ONE value head."""

    def __init__(self, cfg):
        super().__init__(cfg)
        self.wk = nn.Linear(cfg.n_embd, self.head_size, bias=False)  # (C -> D), not (C -> C)
        self.wv = nn.Linear(cfg.n_embd, self.head_size, bias=False)

    def forward(self, x, cache=None):
        B, T, C = x.shape
        q = self.wq(x).view(B, T, self.n_head, self.head_size).transpose(1, 2)  # (B, H, T, D)
        k = self.wk(x).view(B, T, 1, self.head_size).transpose(1, 2)  # (B, 1, T, D)
        v = self.wv(x).view(B, T, 1, self.head_size).transpose(1, 2)
        start = 0
        if cache is not None:
            start = cache.pos
            k, v = cache.append(k, v)
        mask = self.mask[start : start + T, : k.shape[2]]
        att = (q @ k.transpose(-2, -1)) / math.sqrt(self.head_size)  # (B, 1, T, S) broadcasts to H
        att = att.masked_fill(~mask, float("-inf"))
        y = F.softmax(att, dim=-1) @ v
        return self.wo(y.transpose(1, 2).reshape(B, T, C))


class MQAGPT(GPT):
    def __init__(self, cfg):
        super().__init__(cfg)
        for block in self.blocks:
            block.attn = MQAttention(cfg)
        for p in self.parameters():
            nn.init.normal_(p, mean=0.0, std=0.08)

        one_head = GPTConfig(**{**self.cfg.__dict__, "n_head": 1, "n_embd": d})  # (B, 1, T, D)

What they say together: at this size nothing that adds parallel hardware helps. Eight threads and the Apple GPU are both slower, because each op is too small to split and every MPS step pays kernel-launch latency plus a host sync for .item(). bf16 is slower on this CPU and moves the loss only in the fourth decimal place. What does help is fewer, fused ops: SDPA replaces the bmm, mask, softmax, bmm sequence (and its per-matrix bookkeeping) with one kernel and is the biggest single win here; compile is next. Multi-query attention costs a little quality (2.1041 vs 2.0891) for a 4x smaller cache, the trade that grouped-query attention tunes in real models. Even the 201k-parameter model is still too small for the GPU to beat one CPU core at batch 32.

None of this was measured on a CUDA GPU. On one, the same model would still be launch-bound; to see the GPU win you need wide layers, long sequences and big batches, and there bf16 autocast runs the matmuls on tensor cores. If you have a CUDA machine, run python gpt.py bench --device cuda with the bigger config and compare.

import random

import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import DataLoader, Dataset

NAMES_URL = "https://raw.githubusercontent.com/karpathy/makemore/988aa59/names.txt"
IGNORE_INDEX = -100  # cross_entropy skips targets with this value


@dataclass
class GPTConfig:

    block_size: int = 16
    n_layer: int = 1
    n_embd: int = 16
    n_head: int = 4

# --- 1. data and tokenizer ---------------------------------------------------
def load_names(path="names.txt", seed=42):
    """Download once, shuffle with a fixed seed, split 90/10 (the same split as microgpt.py)."""
    if not os.path.exists(path):
        urllib.request.urlretrieve(NAMES_URL, path)
    with open(path) as f:
        docs = [line.strip() for line in f if line.strip()]
    random.Random(seed).shuffle(docs)
    split = int(0.9 * len(docs))
    return docs[:split], docs[split:]


class Tokenizer:
    """One id per character; BOS (the last id) marks both the start and the end of a name."""

    def __init__(self, docs):
        chars = sorted(set("".join(docs)))
        self.stoi = {c: i for i, c in enumerate(chars)}
        self.itos = {i: c for c, i in self.stoi.items()}
        self.bos = len(chars)
        self.vocab_size = len(chars) + 1

    def encode(self, doc):
        return [self.bos] + [self.stoi[c] for c in doc] + [self.bos]

    def decode(self, ids):
        return "".join(self.itos[i] for i in ids if i != self.bos)


# --- 2. batching -------------------------------------------------------------
class NamesDataset(Dataset):
    def __init__(self, docs, tok, block_size):
        self.docs, self.tok, self.block_size = docs, tok, block_size

    def __len__(self):
        return len(self.docs)

    def __getitem__(self, i):
        ids = self.tok.encode(self.docs[i])[: self.block_size + 1]  # at most block_size predictions
        return torch.tensor(ids, dtype=torch.long)

    def collate(self, batch):
        """Right-pad to the longest name: pad inputs are BOS, pad targets are IGNORE_INDEX."""
        T = max(len(ids) for ids in batch) - 1
        inputs = torch.full((len(batch), T), self.tok.bos, dtype=torch.long)
        targets = torch.full((len(batch), T), IGNORE_INDEX, dtype=torch.long)
        for row, ids in enumerate(batch):
            inputs[row, : len(ids) - 1] = ids[:-1]
            targets[row, : len(ids) - 1] = ids[1:]
        return inputs, targets


def batches(ds, batch_size, seed, start_step=0):
    """Endless (inputs, targets) stream whose order depends only on (seed, epoch), so a run
    resumed at start_step sees exactly the batches the uninterrupted run would have seen."""
    per_epoch = len(ds) // batch_size
    epoch, skip = divmod(start_step, per_epoch)
    while True:
        g = torch.Generator().manual_seed(seed + epoch)
        loader = DataLoader(ds, batch_size, shuffle=True, drop_last=True,
                            generator=g, collate_fn=ds.collate)
        yield from itertools.islice(loader, skip, None)
        epoch, skip = epoch + 1, 0


# --- 3. model ----------------------------------------------------------------
class KVCache:
    """Preallocated keys and values for one layer, (B, H, block_size, D), filled left to right."""

    def __init__(self, batch_size, cfg, device=None):
        shape = (batch_size, cfg.n_head, cfg.block_size, cfg.n_embd // cfg.n_head)
        self.k = torch.zeros(shape, device=device)
        self.v = torch.zeros(shape, device=device)
        self.pos = 0

    def append(self, k, v):
        T = k.shape[2]
        self.k[:, :, self.pos : self.pos + T] = k
        self.v[:, :, self.pos : self.pos + T] = v
        self.pos += T
        return self.k[:, :, : self.pos], self.v[:, :, : self.pos]


class CausalSelfAttention(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.n_head, self.head_size, self.sdpa = cfg.n_head, cfg.n_embd // cfg.n_head, cfg.sdpa
        self.wq = nn.Linear(cfg.n_embd, cfg.n_embd, bias=False)
        self.wk = nn.Linear(cfg.n_embd, cfg.n_embd, bias=False)
        self.wv = nn.Linear(cfg.n_embd, cfg.n_embd, bias=False)
        self.wo = nn.Linear(cfg.n_embd, cfg.n_embd, bias=False)
        mask = torch.tril(torch.ones(cfg.block_size, cfg.block_size, dtype=torch.bool))
        self.register_buffer("mask", mask, persistent=False)  # True = may attend

    def forward(self, x, cache=None):
        B, T, C = x.shape
        q, k, v = (w(x).view(B, T, self.n_head, self.head_size).transpose(1, 2)
                   for w in (self.wq, self.wk, self.wv))  # each (B, H, T, D)
        start = 0
        if cache is not None:
            start = cache.pos
            k, v = cache.append(k, v)  # every key/value so far: (B, H, start + T, D)
        mask = self.mask[start : start + T, : k.shape[2]]  # rows: new queries, cols: all keys
        if self.sdpa:
            y = F.scaled_dot_product_attention(q, k, v, attn_mask=mask)
        else:
            att = (q @ k.transpose(-2, -1)) / math.sqrt(self.head_size)  # (B, H, T, S)
            att = att.masked_fill(~mask, float("-inf"))
            y = F.softmax(att, dim=-1) @ v  # (B, H, T, D)
        return self.wo(y.transpose(1, 2).reshape(B, T, C))


class Block(nn.Module):
    """microgpt's block: x + attn(rms_norm(x)), then x + mlp(rms_norm(x)); no norm weights."""

    def __init__(self, cfg):
        super().__init__()
        self.norm1 = nn.RMSNorm(cfg.n_embd, eps=1e-5, elementwise_affine=False)
        self.attn = CausalSelfAttention(cfg)
        self.norm2 = nn.RMSNorm(cfg.n_embd, eps=1e-5, elementwise_affine=False)
        self.fc1 = nn.Linear(cfg.n_embd, cfg.mlp_hidden, bias=False)
        self.fc2 = nn.Linear(cfg.mlp_hidden, cfg.n_embd, bias=False)

    def forward(self, x, cache=None):
        x = x + self.attn(self.norm1(x), cache)
        return x + self.fc2(F.relu(self.fc1(self.norm2(x))))


class GPT(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.cfg = cfg
        self.tok_emb = nn.Embedding(cfg.vocab_size, cfg.n_embd)
        self.pos_emb = nn.Embedding(cfg.block_size, cfg.n_embd)
        self.blocks = nn.ModuleList(Block(cfg) for _ in range(cfg.n_layer))
        self.lm_head = nn.Linear(cfg.n_embd, cfg.vocab_size, bias=False)
        for p in self.parameters():
            nn.init.normal_(p, mean=0.0, std=0.08)  # microgpt's make_matrix init

    @property
    def device(self):
        return self.lm_head.weight.device

    def forward(self, idx, targets=None, caches=None):
        B, T = idx.shape
        start = 0 if caches is None else caches[0].pos
        x = self.tok_emb(idx) + self.pos_emb(torch.arange(start, start + T, device=idx.device))
        for i, block in enumerate(self.blocks):
            x = block(x, None if caches is None else caches[i])
        logits = self.lm_head(x)  # (B, T, V)
        loss = None
        if targets is not None:
            loss = F.cross_entropy(logits.view(-1, logits.size(-1)), targets.view(-1),
                                   ignore_index=IGNORE_INDEX)
        return logits, loss

    def new_caches(self, batch_size):
        return [KVCache(batch_size, self.cfg, self.device) for _ in self.blocks]


# --- 4. training and evaluation ----------------------------------------------
def make_optimizer(model, tc):
    """AdamW with microgpt's betas, decay on matrices only, LR linearly decayed to 0."""
    params = list(model.parameters())
    groups = [{"params": [p for p in params if p.dim() >= 2], "weight_decay": tc.weight_decay},
              {"params": [p for p in params if p.dim() < 2], "weight_decay": 0.0}]
    groups = [g for g in groups if g["params"]]
    opt = torch.optim.AdamW(groups, lr=tc.lr, betas=tc.betas, eps=tc.eps)
    sched = torch.optim.lr_scheduler.LambdaLR(opt, lambda step: max(0.0, 1.0 - step / tc.steps))
    return opt, sched


def train_step(model, opt, sched, inputs, targets, grad_clip):
    model.train()
    _, loss = model(inputs.to(model.device), targets.to(model.device))
    opt.zero_grad(set_to_none=True)
    loss.backward()
    grad_norm = torch.nn.utils.clip_grad_norm_(model.parameters(), grad_clip)
    opt.step()
    sched.step()
    return loss.item(), grad_norm.item()


@torch.inference_mode()
def evaluate(model, ds, batch_size=512):
    """Token-weighted loss over a whole split: (sum of every token's loss) / (number of tokens)."""
    model.eval()
    total, count = 0.0, 0
    for inputs, targets in DataLoader(ds, batch_size, collate_fn=ds.collate):
        logits, _ = model(inputs.to(model.device))
        targets = targets.to(model.device)
        total += F.cross_entropy(logits.view(-1, logits.size(-1)), targets.view(-1),
                                 ignore_index=IGNORE_INDEX, reduction="sum").item()
        count += (targets != IGNORE_INDEX).sum().item()
    return total / count, math.exp(total / count)


def fit(model, opt, sched, tc, train_ds, step=0):
    """Train from `step` to tc.steps, logging the mean loss of each window and tokens/s."""
    it = batches(train_ds, tc.batch_size, tc.seed, start_step=step)
    window, tokens, t0 = [], 0, time.perf_counter()
    while step < tc.steps:
        inputs, targets = next(it)
        lr = opt.param_groups[0]["lr"]
        loss, grad_norm = train_step(model, opt, sched, inputs, targets, tc.grad_clip)
        window.append(loss)
        tokens += (targets != IGNORE_INDEX).sum().item()
        step += 1
        if step % tc.log_every == 0 or step == tc.steps:
            print(f"step {step:5d}/{tc.steps} | loss {sum(window) / len(window):.4f} | "
                  f"grad norm {grad_norm:.3f} | lr {lr:.5f} | "
                  f"{tokens / (time.perf_counter() - t0):,.0f} tok/s")
            window = []
    return step


# --- 5. checkpoints ----------------------------------------------------------
def save_checkpoint(path, model, opt, sched, step, tc):
    state = {"model": model.state_dict(), "optimizer": opt.state_dict(),
             "scheduler": sched.state_dict(), "step": step,
             "model_config": asdict(model.cfg), "train_config": asdict(tc)}
    torch.save(state, path + ".tmp")
    os.replace(path + ".tmp", path)  # atomic: a crash never leaves a half-written checkpoint


def load_checkpoint(path, device="cpu"):
    ckpt = torch.load(path, map_location=device)  # weights_only=True: tensors and plain data only
    model = GPT(GPTConfig(**ckpt["model_config"])).to(device)
    model.load_state_dict(ckpt["model"])
    tc = TrainConfig(**ckpt["train_config"])
    opt, sched = make_optimizer(model, tc)
    opt.load_state_dict(ckpt["optimizer"])
    sched.load_state_dict(ckpt["scheduler"])
    return model, opt, sched, ckpt["step"], tc


# --- 6. generation with a KV cache -------------------------------------------
@torch.inference_mode()
def generate(model, tok, n=10, prefix="", temperature=1.0, top_k=None,
             use_cache=True, seed=None, stop_early=True):
    """Sample n names as one batch. The first forward is the prefill (the whole prompt); after it
    the cached path feeds only the newest token. Rows that already ended keep sampling until all
    rows have; decoding cuts each row at its first BOS."""
    model.eval()
    g = None if seed is None else torch.Generator().manual_seed(seed)
    prompt = [tok.bos] + [tok.stoi[c] for c in prefix]
    idx = torch.tensor([prompt] * n, device=model.device)
    caches = model.new_caches(n) if use_cache else None
    x = idx
    for _ in range(model.cfg.block_size - len(prompt) + 1):
        logits, _ = model(x if use_cache else idx, caches=caches)
        logits = logits[:, -1, :] / temperature
        if top_k is not None:
            kth = torch.topk(logits, top_k).values[:, -1:]
            logits = logits.masked_fill(logits < kth, float("-inf"))
        probs = F.softmax(logits, dim=-1).cpu()  # sample on CPU: one seeded generator, any device
        x = torch.multinomial(probs, 1, generator=g).to(idx.device)
        idx = torch.cat([idx, x], dim=1)
        if stop_early and (idx[:, len(prompt):] == tok.bos).any(dim=1).all():
            break
    names = []
    for row in idx.tolist():
        new = row[len(prompt):]
        end = new.index(tok.bos) if tok.bos in new else len(new)
        names.append(tok.decode(row[: len(prompt)] + new[:end]))
    return names


# --- 7. measurement ----------------------------------------------------------
def bench(model, train_ds, tc):
    opt, sched = make_optimizer(model, tc)
    it = batches(train_ds, tc.batch_size, tc.seed)
    for _ in range(20):  # warm-up
        train_step(model, opt, sched, *next(it), tc.grad_clip)
    tokens, t0 = 0, time.perf_counter()
    for _ in range(300):
        inputs, targets = next(it)
        train_step(model, opt, sched, inputs, targets, tc.grad_clip)
        tokens += (targets != IGNORE_INDEX).sum().item()
    print(f"train    {tokens / (time.perf_counter() - t0):9,.0f} tokens/s  batch {tc.batch_size}")
    for n, reps in ((1, 50), (256, 10)):
        for use_cache in (False, True):
            run = lambda: generate(model, train_ds.tok, n=n, use_cache=use_cache, seed=0,
                                   stop_early=False)
            run()  # warm-up
            t0 = time.perf_counter()
            for _ in range(reps):
                run()
            rate = reps * n * model.cfg.block_size / (time.perf_counter() - t0)
            kind = "cached" if use_cache else "uncached"
            print(f"generate {rate:9,.0f} tokens/s  batch {n:3d}  {kind}")
    from torch.profiler import ProfilerActivity, profile
    with profile(activities=[ProfilerActivity.CPU]) as prof:
        for _ in range(20):
            train_step(model, opt, sched, *next(it), tc.grad_clip)
    print(prof.key_averages().table(sort_by="self_cpu_time_total", row_limit=10))

Where to go from here

  • Read nanoGPT. Karpathy's nanoGPT has the same shape as your gpt.py, scaled to GPT-2 with multi-GPU training. You can now read all of it.
  • Make the cache paged. Your KVCache reserves block_size slots per sequence up front. vLLM's PagedAttention allocates the cache in fixed-size blocks on demand, which is what lets a server pack many sequences of different lengths into GPU memory.
  • Continuous batching. Change generate so finished rows are replaced by new requests instead of idling. That one change is most of what makes a serving engine's throughput.
  • Write the attention kernel yourself. Replace the SDPA call with a fused attention kernel in Triton, check it against your explicit version with allclose, then profile both on a CUDA GPU.
  • Profile on a GPU. Take the bigger config to a CUDA machine, run torch.profiler with ProfilerActivity.CUDA, and open the trace in Perfetto or Nsight Systems. Find the launch gaps, then remove them with CUDA graphs (torch.compile(mode="reduce-overhead")).
